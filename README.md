# Quasar (Fork of Iris)

Quasar is a mobile-born shader engine for Minecraft, optimized for GLES and translated OpenGL environments on mobile devices (such as Android via FearLauncher) as well as desktop platforms.

## Fork Notice & License
This project is a fork of [Iris](https://github.com/IrisShaders/Iris), originally developed by the Iris team (coderbot, IMS212, Justsnoopy30, FoundationGames, and contributors).
Quasar retains Iris's rendering pipeline logic while modifying shader transpilation, capability probing, format handling, and UI to ensure crash-proof operation on mobile GLES and desktop contexts.
